System Design — Path Co-Creation Flow

Bubble-Picker Interface → Multimodal Prompt Generation → 2D / VR Output

Player
1 Path Co-Creation Interface Web-based
1

Language

Player selects a language to begin — no chat step in this flow.

2

Intro

Shows an illustrated intro image and plays a narrated voice guide.

3

Bubbles — 4 Quick Choices

Tree-structured chip picker for season, weather, time, and light. Confirm at any depth, or type a custom answer.

4

Confirm

One OpenAI call turns the selections into the same three-prompt JSON shape the rest of the system uses.

Scene Concept Fixed, not collected
  • Always a road extending into the distance, flanked by trees on both sides
  • Season, weather, time, and light — 4 choices only
  • No place, sound sources, or spatial layout collected
  • Forbids people, buildings, vehicles, signage, text
5 Multimodal Prompt Generation
One OpenAI Responses call turns the confirmed selections into modality-specific prompts — the same shape the chatbot front end also produces.

* Background music prompt is generated but synthesis is currently disabled.

6a 2D Mode Generation Web + API

2D Image Generation

Flattened environment prompt → OpenAI image API → single flat scene image.

Ambient Sound Generation

Sound prompt → ElevenLabs or fal.ai (Stable Audio) → looping ambient sound.

↔
Shared Prompt
JSON file

Saved locally as generated_prompt.json and consumed by both 2D and VR pipelines through the same endpoints.

6b VR Mode Generation Unreal Engine

360° Visual Environment Generation

Un-flattened panorama prompt → OpenAI image API → PNG → HDR.

Ambient Sound Generation

Same sound prompt → ElevenLabs or fal.ai → WAV via ffmpeg for Unreal.

⚡ Pregenerated (fast path)

Python runs the two calls above ahead of time to a fixed, overwrite-in-place path. Unreal imports instantly at “start experience.”

↪ Live (fallback)

Blueprint nodes call OpenAI/ElevenLabs directly on click, blocking the editor thread while generation runs.
